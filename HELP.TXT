Tap Caps Lite — Help

Run TapCapsHotkeyToggle.exe to enable the Tap Caps hotkey.
Press the hotkey Caps+A (Capslock+A) to launch Tap Caps.
Tap Caps will paste to any document that has the focus.

Tap Caps allows fast pasting of your favorite symbols and
emojis into any text. You can keep the palette visible or
minimized while typing.

You can click the palette cells for visual pasting or use the
Tap Caps keyboard shortcuts. The shortcuts are often faster
than clicking. Your hands don't have to leave the keyboard to
navigate and click the palette cells.

------------------------------------------------------------
Keyboard shortcuts for quick tap‑pasting:

Tap (press and release) Caps key, then you can paste any of:
• 18 characters with one key tap
• 162 characters with two key taps
• 324 characters with three key taps

Some characters may appear in black fallback font inside
the palette, but they paste in their correct color.

------------------------------------------------------------
Pasting Characters After Tapping Caps

• Tap a column letter to paste a character from row 1.
   Example: Caps → Q pastes row1/columnQ
• Tap one or two digits to select rows 1–18.
• Then tap a column letter to paste the chosen NxL cell.

------------------------------------------------------------
Other Caps Commands
Tap Caps, then:

• [`/~] key with tilde → toggles persistent mode.
   The palette can stay open or close after a single paste.
   The ℗ character toggles in the upper left corner of palette.

• U → Displays the next symbol set in the palette. Up to 9
   sets can be saved in the Tap Caps folder; SymbolSet1.txt
   through SymbolSet9.txt. Missing sets are ignored.

   Note: Set files MUST be saved as UTF-8 BOM encoding so
   that emojis are stored correctly. You can copy one of the
   existing set files and edit it. If you create a new file in
   Notepad, the encoding is chosen in the save dialog box.
   In Notepad++, select Encoding at the top of edit window.

• O → Toggles the palette between displayed and minimized.
   While hidden, you can paste characters freely into your
   documents using Tap Caps keyboard shortcuts. 
  ★ Stay aware that Caps key is still controlled when minimized ★

Esc or the window’s X button closes Tap Caps.

------------------------------------------------------------
Notes on Caps Commands

Commands are chosen for hand convenience:
• Caps is a big command key.
• Tilde and Esc are near the command key.
• Column letters are the QWERTY keys and below.
• U, O are a low‑travel reach from the right‑hand home row.

     Left hand           Right hand
[Esc]    [QWERTY]      [U O]
[ `/~ ]    [ASDFGH]
[Caps]   [ZXCVBN]

------------------------------------------------------------
Character Exploration

Tap Caps encourages playful character exploration.
Open a symbol set, then press Win+. to open the 
Windows emoji/symbol picker. Scroll down and click 
whichever symbols or emojis catch your interest.
You can create up to 9 SymbolSetn.txt files in the folder.

Newlines (Enter) and spaces allow the user to format
the set files and thus the palette display to their liking.
