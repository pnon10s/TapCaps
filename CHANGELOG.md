⭐ Release v2.2.0

Tap Caps v2.2 — Release Notes

New
Persistent mode now saves to TapCaps.ini  
Tap Caps remembers whether you prefer it to stay open after paste.
The persistent toggle is now a true user preference instead of a temporary session state.

Improved
Persistent icon behavior is consistent  
The © indicator now reflects only the user’s chosen persistent mode, never temporary internal behavior.

Minor polish around window restore and status line  
Small refinements to keep the palette feeling smooth and predictable.

Installation Notes
Windows may show a SmartScreen warning because the app isn’t digitally signed. Choose More info → Run anyway to start the app.

⭐ Release v2.1.0

New
Set switching (Caps→U)  
Tap Caps now supports multiple symbol sets. Switch instantly without reopening the app.

Improved
Hidden‑mode behavior is consistent  
Esc shows a small tooltip before Tap Caps closes silently.

Arrange mode only activates when visible  
Prevents accidental layout editing while hidden.

Help window closes cleanly  
Esc and Caps now close the help overlay instead of exiting the app.

General polish  
Status line updates, window‑restore cleanup, and several small UX refinements.

Notes
Windows may show a SmartScreen warning because the app isn’t digitally signed. This is common for small utilities like Palette Picker. Choose More info → Run anyway to start the app.
