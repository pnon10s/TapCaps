# Tap Caps — Overview

Tap Caps is a small, fast utility for inserting your favorite symbols, emojis, and special characters from your own palette into any text box. Press a hotkey, click a character, and the Picker pastes it instantly and closes.

**Tap Caps is a Windows‑only utility, designed for speed, simplicity, and everyday use.**

## First‑Run Setup

- Run **TapCapsHotkeyToggle.exe** to enable the hotkey.  
- Now press the hotkey in any text box to open the Picker instantly.

---

## Quick Start (Try This First)

- If you haven’t already, run **TapCapsHotkeyToggle.exe**.  
- Open any app with a text box and place the cursor.  
- Press **Ctrl+⁇** (where ⁇ is your chosen key) to open the Picker.  
- Click any character or emoji.

The Picker will paste the character into your text and close. Perfect for quick pasting of your favorite symbols. The Picker can be kept open for multi‑symbol pasting and other features, like editing the palette.

## Files Included

- **TapCaps.exe** — The main Picker tool  
- **TapCapsHotkey.exe** — Hotkey helper  
- **TapCapsHotkeyToggle.exe** — Hotkey helper installer  
- **SymbolSet1.txt** — Full set of characters and emojis  
- **SymbolSet2.txt** — One row set of characters and emojis  
- **SymbolSet3.txt** — Dummy set with just a message 
- **TapCapsHelp.txt** — Full details. The Picker opens this help file.
